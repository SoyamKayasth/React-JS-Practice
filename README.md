# ReactJS Practice & Projects

A collection of my **ReactJS learning journey**, practice code,
experiments, and small projects.

This repository documents my progress while learning React and building
projects from basic concepts to more interactive applications. Along the
way, I also explored **Tailwind CSS** and the fundamentals of **Redux
and Redux Toolkit**.

## About This Repository

I created this repository to keep all of my ReactJS practice code and
projects in one place.

During this journey, I learned and practiced many important React
concepts, including:

-   React components
-   JSX
-   Props
-   State management
-   Event handling
-   Forms in React
-   Conditional rendering
-   Lists and keys
-   React Hooks
-   `useState`
-   `useEffect`
-   Component-based architecture
-   Basic state management patterns
-   Building reusable UI components
-   Working with APIs
-   Basic Redux
-   Redux Toolkit
-   Tailwind CSS
-   Responsive UI design

The repository also contains several small projects that helped me
understand how these concepts are applied in real applications.

## React Learning Journey

My ReactJS journey started with the fundamentals and gradually moved
toward building complete small applications.

### 1. React Fundamentals

I practiced:

-   Creating React applications
-   Components and JSX
-   Props
-   State
-   Event handling
-   Conditional rendering
-   Rendering lists
-   Forms

### 2. React Hooks

I worked with important React Hooks such as:

``` jsx
useState()
useEffect()
```

These helped me understand state management, side effects, and dynamic
UI updates.

### 3. Styling & UI

I also learned how to create modern and responsive interfaces using:

-   CSS
-   Tailwind CSS
-   Material UI

### 4. State Management

I explored the basics of:

-   Redux
-   Redux Toolkit
-   Managing application state
-   Creating slices
-   Dispatching actions
-   Reading state from the store

### 5. Building Projects

After learning the fundamentals, I applied the concepts by building
small projects such as a To-Do App, Lottery Game, Review Form,
Interactive Card, Ludo Dice Counter, and Weather App.
